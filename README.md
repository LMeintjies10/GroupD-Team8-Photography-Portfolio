# Photography Portfolio

A responsive, single-page photography portfolio showcasing a curated image gallery, a short about section, and a contact form for booking photoshoots.

## Features
- Responsive layout for mobile, tablet, and desktop.
- CSS Grid gallery with `object-fit: cover`.
- Flexbox for navigation and layout elements.
- Semantic HTML5 and custom CSS variables.
- Smooth navigation and contact section.
- No frameworks or horizontal scrolling.

## Technologies
- HTML5
- CSS3

## Getting Started
Open `index.html` in your browser to view the website.
